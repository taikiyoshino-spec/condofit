# CondoFit 実装時の決定事項

`CONDOFIT_SPEC_LATEST.md` で未定義・解釈が分かれた点について、実装前に合意した内容（2026-09-30）。

| # | 項目 | 決定 |
|---|---|---|
| 1 | 新羽店の座標 | サーバー側の環境変数 `GYM_LAT` / `GYM_LNG`（ブラウザには渡さず、判定はサーバーのみ）。未設定時はチェックイン不可。仮値で判定を確定させない |
| 2 | フレームワーク | Next.js (App Router) + TypeScript + Supabase |
| 3 | 認証 | Supabase Auth に内部ダミーメール（`<user_id>@users.condofit.invalid`）で載せる。PINはサーバー側でペッパー付きで派生させたパスワードに変換（4桁 < 最小6文字のため）。PINハッシュ（scrypt）は他メンバーから読めない `user_secrets.pin_hash` に保持。ログイン失敗5回で15分ロック（表示名単位） |
| 4 | 初期構成 | グループは1つ。初回 admin は seed スクリプトで作成 |
| 5 | 圏外での再取得 | 50m以内のときのみ `last_location_verified_at` を更新。圏外は更新しない。チェックアウトもしない |
| 6 | 15分確認通知 | Supabase pg_cron + pg_net で毎分 Next.js の `/api/cron/tick` を呼び、判定して Web Push（ベストエフォート。プッシュ送信処理をアプリ側と共通化するため Edge Function ではなくこちらにした）。アプリを閉じると位置取得できないため実質「閉じて約15分後に通知」 |
| 7 | 種目タブ今月代表値 | 重量系: 今月の最大重量とその回数（同重量なら回数が多い方）。有酸素: 今月で合計値が最大のセッション1回分 |
| 8 | 予定作成者 | 作成時に自動で「行く！」。後から変更可 |
| 9 | Fit訪問回数 | **チェックインは集計に使わない**。訪問回数 = トレーニングセッション数、トレーニング日数 = セッションのある日数（JST）。「〜がFitに行きました」はセッション記録時に表示。チェックインは「今やってる」のアピール用（Fit中表示・プッシュ通知）のみ |
| 10 | 記録日時の初期値 | 当日(JST)のチェックインがあればその日時、なければ現在日時 |
| 11 | 単位 | 重量 kg（0.5刻み）、時間 分、距離 km。小数可 |
| 12 | 初期部位 | プリチャーカール=腕、ショルダープレス=肩 |
| 13 | 予定編集 | 変更先は今日以降のみ |
| 14 | タイムゾーン | JST 固定 |
| 15 | 規約/プライバシー | プレースホルダ文面 |
| 16 | 最近の活動 | 直近7日・最大20件を都度集計（専用テーブルなし） |
| 17 | 実行リージョン | Vercel Functions は東京（hnd1）で実行する（`vercel.json`）。Supabase（東京）との往復遅延を避けるため |
| 18 | 総合ランキング（仕様変更） | 2026-10-01 に仕様書を変更し追加。基準は Fit訪問回数・種目の数、月間集計、ホームに上位3人＋専用画面。種目の今月にも順位を付ける |
| 19 | プロフィール画像 | 写真アップロード（端末で256pxに縮小、非公開バケット、/api/avatar でメンバーにだけ配信）。ログイン画面は端末で使った人だけを表示 |
| 20 | インストール案内 | ログイン後のホーム上部に表示。Androidは beforeinstallprompt でボタン、iOSは手順案内（「追加した」で非表示）。ホーム画面から起動中は出さない。「あとで」で7日間非表示。状態は端末の localStorage のみ |
| 21 | プッシュ通知のおすすめ | 通知に対応し、この端末で未登録の人にホームでカード表示。「閉じる」はログインのセッションIDと結び付けて端末内に記憶し、再ログインで再表示。通知ブロック中・非対応環境では出さない |
| 22 | 成長グラフ・自己ベスト | 自分の記録のみ。重量系は最大重量・総挙上量・推定MAX（Epley、15回以下）、有酸素は時間・距離を切り替え。横軸は記録ごと等間隔。保存時に過去の自分を上回った指標（最大重量・総挙上量・時間・距離）をお祝い表示。グラフ色は validate_palette で light #1f8a4c / dark #33a865 を確認 |
