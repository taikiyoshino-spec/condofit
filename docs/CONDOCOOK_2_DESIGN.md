# CondoCook フェーズ2 設計（買い物リスト）

RECIPE_SPEC.md の D8・D19・D23④ を実装する。2026-10-19。マイグレーション `20261019000002_cook_shopping.sql`。

## 1. 買い物リスト（`shopping_items`）
- 家族で1つ。見る・消すは自分の家族の分だけ（RLS）。追加・買った・食材リストへは RPC
- レシピから追加した材料は1行ずつ持ち、画面で同じ食材（食材マスタが同じ、またはマスタにない同じ名前）を1行にまとめる。分量は足さず「親子丼 300g・唐揚げ 500g」のように添える（`src/lib/cook/shopping.ts`）
- 売り場の分類（食材マスタの分類）順に見出しを付けて並べる
- 同じレシピの同じ材料が、まだ買っていない状態でリストにあれば足さない（同じレシピを2回入れても重ならない）
- 家族の変更は Realtime で画面に反映する

### レシピから入れる
- レシピ画面の材料の下の「買い物リストに入れる」。選んだ人数分に換算した分量で入れる
- 最初からチェックを外すもの: 家にある（食材リストにある）、いつもある（食材マスタの `is_staple`。家族ごとの設定はフェーズ3）、もうリストにある、なくても可

### 手で入れる
- リストの上の欄。食材の候補を出し、選ぶと食材としてまとまる（名前が食材マスタと一致すれば自動でつなぐ）

## 2. 買った → 食材リスト（`pantry_items`）
- 買い物中は「買った」の印を付け外しできる（買ったものは下にまとめる）
- 「買ったものを食材リストへ」で家にある食材として記録し、リストから消す（`move_bought_to_pantry`）
- 食材リストは1食材1行。量は持たない（D8）。もう一度買うと買った日と期限の目安を新しくする
- 期限の目安 = 買った日 + 食材マスタの冷蔵の日数（D11）。食材リストの画面・期限切れの整理はフェーズ3

## 3. 通知（D23④）
- 家族が追加したら、追加が続く間はまとめ、その人の最後の追加から5分たったら家族（追加した人以外）へ1回「〇〇さんが買い物リストに3品追加しました」
- 毎分の定期処理（`/api/cron/tick`）から `flush_shopping_notifications()` を呼び、作った通知と同じ相手にプッシュを送る
- 設定: `notification_settings.cook_shopping`（CondoCook の「マイ」）

## 4. 画面
- 下部タブに「買い物」を足した（レシピ・ランキング・買い物・登録・マイ）
