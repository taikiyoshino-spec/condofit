# CondoCook フェーズ3 設計（食材リスト・提案）

RECIPE_SPEC.md の D8〜D11・D17 を実装する。2026-10-19。マイグレーション `20261019000003_cook_pantry.sql`。

## 1. 食材リスト（`/cook/pantry`、`pantry_items`）
- 家族で共有。量は持たず「ある／ない」だけ（D8）。1食材1行
- 入れ方: ①買い物リストの「買ったものを食材リストへ」 ②上の欄から手で（あいまいな入力でも候補を出す） ③「よく買う物から追加」（過去に買った物 `household_purchases`。よく買う順に、いま家にない物を20件まで）
- 食材を押すと: 冷蔵・常温／冷凍の切り替え、期限の目安の変更、買い物リストに入れる、ない（消す）
- 期限の目安 = 買った日 + 食材マスタの日数（冷凍にすると冷凍の日数で計算し直す）。もう一度買うと買った日と期限を新しくする（冷凍のものは冷凍のまま）
- 期限: 過ぎたものは「期限切れ」、2日以内は「あと◯日」「今日まで」で目立たせる
- 「期限切れをまとめて消す」: 期限切れの食材を一覧で出し、初期値は全部チェック。消さないものは外してから消す（D11）
- 分類（売り場）ごとに、期限の近い順

## 2. いつもある（D9、`household_staples`）
- 初期値は食材マスタの `is_staple`（塩・砂糖・しょうゆ・油など）。家族ごとに外したり足したりでき、初期値との差分だけを持つ
- 食材リストの画面の下にまとめる。在庫の出し入れはせず、切らしたら「買う」で買い物リストに入れる
- 提案・買い物リストへの追加・使い切った？では「ある」として扱う

## 3. 使い切った？（D10）
- 「作った！」を記録したあと、そのレシピで使った家にある食材（いつもあるものを除く）を出し「使い切った食材はありますか？」と聞く。初期値はチェックなし。チェックしたものを食材リストから消す

## 4. レシピの提案（`/cook/suggest`、D17）
- 家にある食材を1つ以上使うレシピを、①買う物が少ない順 ②同じなら期限が近い食材を使う順 ③お気に入り＋作られた数 で並べる。1週間以内に家族が作ったものは下げる
- 買う物には、なくても可・いつもある・家にある材料を数えない。食材マスタにない材料は名前（表記ゆれをそろえて）で比べる
- 各レシピに、買う物の数と名前、使う期限が近い食材、人気、写真のサムネイルを出す。カテゴリで絞り込める
- 計算は `src/lib/cook/pantry.ts`（純粋関数・テストあり）
